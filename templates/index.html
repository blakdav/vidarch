vidarch

Paste video links and download them to the archive volume. Takes plain page URLs, lines with a filename attached, or a raw manifest dump from the browser network panel.

Getting links out of a browser

Two approaches. Try the first — it produces permanent links and real filenames. Fall back to the second only when the player's page URL can't be resolved.

Page links

Many players load videos from a host that yt-dlp already understands. If you can find a stable page or embed URL for each video, paste those directly, one per line. Filenames come from the source's own metadata.

When the source's stored titles are unhelpful, or you want a specific order on disk, prefix each line with an output name:

-o "01 - First Video.%(ext)s" https://host.example/video/123
-o "02 - Second Video.%(ext)s" https://host.example/video/456

The numeric prefix is what preserves ordering, since files sort by name rather than by when they finished downloading.

Manifest capture

Use this when the page builds video URLs in a way that can't be reproduced outside the browser.

  1. Open the page and press F12 to open developer tools.
  2. Switch to the Network panel and tick Preserve log so entries survive navigation.
  3. Type m3u8 in the filter box. If nothing appears while a video is playing, click the Media type tab instead — the text filter can miss entries.
  4. Play or scroll through each video so its player initialises. A player that never loads makes no request and won't be captured.
  5. Right-click any row and choose Copy all listed URLs.
  6. Paste the whole dump below. Video-only renditions, segments, and duplicate captures are filtered out automatically.

If the player sits in an iframe and the panel looks empty, right-click the video itself and choose Inspect — that reattaches developer tools to the player's own frame.

Signed links expire. Most are valid about an hour from capture. Work in batches and start the download soon after pasting rather than collecting everything first.

Referer

Some hosts only serve video when the request claims to come from the site that embeds it. If a download fails with a permission or embed error, put the page URL that contains the player in the referer field. One value usually covers every video on the same site.
